Інструмент для моніторингу тріґерів контролера під час використання.

Альтернатива до системих інструментів.

Може використовуватися на другому моніторі під час гри, для нагляду за несправними тріґерами.

Зроблено як для фанатів `графічних інтерфейсів`, так і для поціновувачів `терміналу`.

## Вимоги

Щоб запустити цей застосунок, необхідні [Python](https://python.org) та [uv](https://docs.astral.sh/uv/)

## Встановлення

### 1. Завантаження

Можна використати буль-який з цих методів:

- Завантажити ZIP файл: [Як завантажити архів з вихідним кодом](https://docs.github.com/en/repositories/working-with-files/using-files/downloading-source-code-archives)
- Клонувати за допомогою `git` (потрібен [Git](https://git-scm.com/)): [Як клонувати репозиторій](https://docs.github.com/en/repositories/creating-and-managing-repositories/cloning-a-repository)

### 2. Налаштування

Виконайте ці кроки після завантаження вихідного коду і вимог.

1. Відкрийте завантажену папку в `терміналі`
2. Виконайте команду `uv sync` щоб встановити залежності

### 3. Використання

Після завершення налаштування, під'єднайте контролер і виконайте команду `uv run main.py` в папці проєкта щоб запустити застосунок.

Цей застосунок має *два* користувацькі інтерфейси:
- Графічний (стандартно)
- Консольний

Ви можете вибрати який саме ви хочете використовувати перед запуском застосунку, додавши один з цих аргументів до команти запуску:
- `--gui` щоб навмисно вибрати графічний інтерфейс (`uv run main.py --gui`)
- `--cli` щоб вибрати консольний інтерфейс (`uv run main.py --cli`)
